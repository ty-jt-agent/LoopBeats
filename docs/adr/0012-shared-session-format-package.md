# Share the portable session format implementation across hosts

Status: accepted design boundary, 2026-10-24; native bulk-transfer integration requires prototype validation.

Move the existing versioned ZIP/WAV encoding, import validation, and sample-rate conversion into a nonempty TypeScript `packages/session-format` package shared by the Web application and Windows Tauri frontend. Preserve the existing session format versions, limits, validation messages/behavior, conversion algorithm, cancellation, and progress behavior; extraction is not a format redesign or algorithm change. Keep the package independent of React, Web Audio, Tauri, filesystem and browser storage APIs, Web Locks, and `MessageChannel`. Express cancellation/progress and cooperative yielding through a small explicit host-supplied mechanism. File selection, persistence, recovery coordination, and host-specific scheduling remain in platform adapters. Device IDs and backend preferences remain outside portable session files.

The Windows frontend uses the same TypeScript package outside the real-time audio path. It exchanges manifests and bounded audio chunks with the native host through a separate operation-tokened transfer protocol with explicit acknowledgement/backpressure; no sample data travels through the render callback. Prefer the existing one-outstanding-chunk/2,048-frame pattern pending measurement. The Rust host performs native bounds, value, and engine-invariant checks, but does not implement a second ZIP/WAV codec or sample-rate converter without a separate decision. Prototype the cost of IPC serialization, memory copies, cancellation, UI responsiveness, and native snapshot/staging ownership before finalizing the integration. Preserve the current sample semantics and prove both frontends use the same codec fixtures. Manual import/export is in the planned Windows integration scope; Windows automatic recovery/checkpoints are deferred as specified in [ADR-0013](0013-windows-recovery-deferral.md). Existing Web recovery remains unchanged. See [ADR-0002](0002-portable-sessions-and-recovery.md) for portable session semantics.
